*Quantifying what makes humanitarian crises worse — and who bears the burden. Reproducible data science on open UN-affiliated data.*

## Overview

This project performs reproducible, analysis-driven data science entirely on
open, United Nations–affiliated datasets: EM-DAT disaster records (obtained via
the Humanitarian Data Exchange), UNHCR displacement statistics, and World Bank
development indicators. The driving question is accountability — which
combinations of hazard, exposure and governance factors make humanitarian
outcomes measurably worse, and which populations carry disproportionate
burden. The project lives in the `humanitarian-data-project/` subdirectory of
this repository: notebooks under `notebooks/`, reusable code under `src/`,
source data under `data/`, and generated visuals under `figures/`.

## Features

- **Open-data only** — every input is publicly downloadable, so every figure can be regenerated by anyone.
- **Reproducible pipeline** — pinned dependencies in `requirements.txt` and a notebook-first workflow with shared utilities in `src/`.
- **Multi-source joins** — EM-DAT, UNHCR and World Bank indicators aligned on country and year for cross-source analysis.
- **Figure output** — publication-ready charts written to `figures/` for reuse in reports and write-ups.

## Getting started

```bash
git clone https://github.com/collins-muchiri/humanitarian-data-project.git
cd humanitarian-data-project/humanitarian-data-project
pip install -r requirements.txt
jupyter lab   # open the notebooks under notebooks/
```

Datasets are placed under `data/`; each notebook documents the exact source
and retrieval step for the files it expects.

## Usage

The notebooks proceed from ingestion (download and normalize EM-DAT, UNHCR and
World Bank extracts) through cleaning and country-year alignment to analysis
and visualization. Figures written to `figures/` are regenerated end-to-end by
running the notebooks in order, making the analysis auditable from raw data to
final chart.
